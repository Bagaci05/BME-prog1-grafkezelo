# A Program Specifikációka

## 1. A program alapvető működése
### 1.1 A program futtatása
A programnak kettő argumentumot lehet beadni futtatáskor:
- Bemeneti file (required)
- Kiemeneti file (optional)
A program futtatáskor beolvassa a bemeneti filet (2. Bekezdés) majd azt eltárolja egy adatstruktúrában (4. Bekezdés).
Ezt követően jelenik meg egy egyszerü menü, ahol a felhasználó el tudja dönteni melyik algoritmust szeretné futtatni. 
```
========== GRAFKEZELO ==========

1. BFS bejárás
2. DFS bejárás
3. Dijkstra
4. Gráf adatainak megjelenítése
5. Kilépés

Választás:
```

Algoritmus kiválasztása után, bekéri a felhasználótól az algoritmushoz szükséges bemeneti információkat (3. Bekezdés) és utána választott algorutmustól függően kiírja filba az elkészített gráfot, vagy a meghatározott legrövidebb útvonalat.

### 1.2 A program működése
#### Permission denied file: 
A program ha olyan filet adunk neki bemenetnek/kimenetnek amihez a user aki futtatja nem fér hozzá megjelníti a problémát 1-es hibakóddal tér vissza.
#### Nem létező file
A program ha nem létező filet adunk neki bemenetnek megjelníti a problémát és hibakóddal tér vissza.
#### Hibás file
A program ha hibásan tagolt filet adunk neki bemenetnek megjelníti a problémát és hibakóddal tér vissza.
#### A menü helytelen használata:
A menü helytelen használatakor, a menü prompt újra indul, közli a felhasználóval a hibát. Ez arra is vonatkozik, ha a felhasználó nem létező kezdőcsúcsot adunk meg az alogritmusnak.
#### Egy él duplikáltan létezik: 
Amennyiben a forrásfileban egy él duplán szerepel az duplán is értelmezendő. Mivel a Bfs, Dfs és dajkstra nem várja el, hogy egyszerű gráfot kaprjanak így nem okoz gondot. 
#### Érvénytelen él súly 
Negatív élsúly esetén a program megjelníti a problémát és hibakóddal tér vissza.

## 2. Fileból olvasás: 
A program egy .csv fileból fogja beolvasni egy éllistát, ami a gráf irányított éleit tartalmazza. A CSV file minden sora egy élnek fog megfelelni. A CSV file tartalmazza a két csúcsot és az él súlyát.

A program ugyan ebben a formátumba fogja az elkészített gráfokat is filbe kiírni. 

A 3 érték:
- src: Az él kiinduló csúcsa. Értéke: ``INT``
- dst: Az él céljának a csúcsa. Értéke: ``INT``
- w: Az él súlya. Értéka: ``Pozitív FLOAT

Példa CSV file:
```csv
src;dst;w
1;2;1.0
2;1;1.0
1;3;2.0
3;1;2.0
2;4;4.0
4;2;4.0
```

## 3. Algoritmusok:
### 3.1 Breadth-First Search:
Azaz szélességi bejárás. Az algoritmus megvizsgálja a kezdő csúcs (L0) összes szomszédját majd az a felfedehzett élek (L1) szomszédait és így tovább. így kapjuk meg a feszítőfánkat.

Az algoritmusnak bemenetei/kimenetei:
- IN gráf: Ez tartalmazza
- IN csúcs: Ez a kezdő csúcs, ahonnan indul az algoritmus
- OUT gráf: Az így elkészített feszítőfája a gráfnak kiírva a kiementi fileba

### 3.2 Depth-first search:
Azaz mélységi bejárás. AZ algoritmus megvizsgálja kezdő node szomszédját és az első találatkor megvizsgálja annak a node-nak a szomszédját, amit talál ugyanúgy megy annak a szomszédjára. Ha már nem talál több nodeot akkor megy a "felsöbb" node következő szomszédjára. Így kapunk egy feszítőfát a végén.

Az algoritmusnak bemenetei/kimenetei:
- IN gráf: Ez tartalmazza
- IN csúcs: Ez a kezdő csúcs, ahonnan indul az algoritmus
- OUT gráf: Az így elkészített feszítőfája a gráfnak kiírva a kiementi fileba

### 3.3 Dijkstra:
Ez egy keresési algoritmus ami számításba veszi az "út" költségét is. Így ennek az algoritmusnak a végén kapok egy táblázatot, a kezdő node-tól való távolságról. 

Az algoritmusnak bemenetei/kimenetei:
- IN gráf: Ez tartalmazza
- IN csúcs_start : Ez a kezdő csúcs, ahonnan indul az algoritmus
- IN csúcs_end: Ez a cél csúcs, ide keresi meg a legrövidebb útvonalat
- OUT csúcslista: A start csúcstól a cél csúcsik a legrövidebb megjelenítése illetve a szomszédossági tábla kiírása fileba 

```
Dijkstra eredménye

Kezdőcsúcs: 1
Célcsúcs: 5

Legrövidebb út:
1 -> 2 -> 4 -> 5

Összsúly: 11.0
```
